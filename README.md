### Selected work

**RideGuard: crash-risk system for Dhaka motorcyclists** · IEEE COMPAS 2026
- 🧪 **[RideGuard_V1](https://github.com/rakib4123/RideGuard_V1)**: the model. Calibrated CatBoost, conformal prediction, drift detection and SHAP, plus a leakage audit that showed the data held little real pre-crash signal.
- 📱 **[Ride_Guard_WebApp](https://github.com/rakib4123/Ride_Guard_WebApp)** · [Live ↗](https://ride-guard-web-app-web.vercel.app): the product. A FastAPI service serves the model to a NestJS API and a Next.js front end, with a live risk map, route risk and voice alerts.

**DhakaNight: night-time traffic detection** · ICCA 2026
- 📦 **[Dhaka-Night_DataSet](https://github.com/rakib4123/Dhaka-Night_DataSet)**: 2,380 night-time Dhaka street images with 45,000+ boxes across 10 classes, built and labelled by me.
- 🔬 **[Dhaka_Night](https://github.com/rakib4123/Dhaka_Night)**: YOLOv8 benchmarked against four low-light enhancement methods. A larger detector helped; brightening the images did not.

**Full-stack**

- 🤖 **Durbar Robotics** (part-time): building [durbarrobotics.com](https://durbarrobotics.com), a robotics-parts store, course platform and 3D-printing quote tool (Next.js).
